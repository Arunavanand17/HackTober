# 🎃 HackTober 2026 - Bug Fixing & DSA Contribution

Welcome to the official **HackTober** repository! This project is designed for beginners (25th and 26th batch) to learn open-source contribution workflows, Git fundamentals, and basic bug-fixing techniques.

---

## 🎯 Objective

This repository contains intentional logical or syntax bugs in standard Data Structures & Algorithms (DSA) problems written in **C++** and **Java**. Your goal is to identify open issues, fix the code, and submit a successful Pull Request (PR).
